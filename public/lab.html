🐢 Building in public

Turtle Lab

The live build log for TurtleBlock AI's conversational constructivist agent and persistent WorldSpec architecture.

Current milestone

Discord /turtle now has an LLM-backed opening-turn architecture. Discord receives an immediate deferred acknowledgement, Turtle reasons under the Turtle Charter, and the richer conversational reply is written back into the original Discord interaction. If the LLM secret is unavailable, Turtle falls back to deterministic behavior rather than failing.

What the first field test taught us

The plumbing worked. The interpretation was too shallow. A rich learner description of an abandoned village, remembered order, disarray, hope, light, and rebirth was compressed into a small set of known parser cells. That field test changed the architecture.

lossless learner language → retrieve current project state → Turtle dialogue → incremental WorldSpec revision → learner-authorized construction → inhabit → notice → reflect → revise

Conversation before construction

  • Turtle is a conversational collaborator governed by the Turtle Charter, not a one-shot parser.
  • The deterministic parser remains useful as a structured signal, but it no longer defines the limits of what Turtle can notice.
  • The learner's original language is retained even when Turtle has no existing lexicon entry for it.
  • Turtle should mirror, notice, interpret provisionally, and ask one or two generative questions at a time.
  • The learner remains in control of when conversation becomes construction.

LLM, RAG, and trust boundaries

The conversational model receives trusted Turtle Charter instructions separately from untrusted learner text and project data. Learner messages, retrieved documents, Discord history, Minecraft text, and previous model output are treated as data rather than authority. The model may propose interpretations and future actions; deterministic application code decides what can actually mutate WorldSpec, Discord, or Minecraft.

RAG will retrieve the current WorldSpec, active constraints, learner-defined meanings, unresolved concepts, relevant revisions, and intentionally attached project materials. Retrieval augments Turtle's conversation without replacing the canonical WorldSpec.

Persistent WorldSpecs

Every Turtle Lab is intended to create a persistent WorldSpec instance immediately. Each learner turn should append a conversation turn and produce an incremental WorldSpec delta, creating revision 0001, 0002, 0003, and onward rather than regenerating the project from scratch.

Discord Turtle Lab

The next interaction milestone is true multi-turn dialogue: /turtle idea:... starts or resumes a dedicated Turtle Lab thread, and ordinary messages inside that thread continue the same session and WorldSpec.

Next implementation target

Persist Turtle Lab sessions and WorldSpec revisions in D1, then connect Discord thread messages to the same session so Turtle can remember, retrieve, revise, and continue the dialogue naturally.

Build-in-public rule

Meaningful architecture, pedagogy, integration, research-data, security, and WorldSpec milestones are reflected on the public TurtleBlock AI site as part of the same work cycle. Failures and reversals count as milestones too.
