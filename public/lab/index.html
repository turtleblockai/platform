🐢 Building in public

Turtle Lab

The public edge of TurtleBlock AI: build notes, learner-approved projects, WorldSpec artifacts, experiments, reflections, and things we learned by making them.

Current milestone

Discord /turtle is live, LLM-backed opening dialogue is wired, and the persistence layer now has explicit Turtle Lab session, turn, WorldSpec revision, and publication records.

Private conversation, public artifact

A Turtle conversation is private by default. Turtle Lab is not intended to publish a raw stream of Discord dialogue. Instead, a learner may deliberately publish a project record containing selected artifacts: a title, learner-approved summary, a WorldSpec snapshot or revision history, screenshots or builds, selected dialogue if desired, and reflection on what changed through the work.

private dialogue → persistent WorldSpec → learner chooses what to publish → curated Turtle Lab artifact

Published Turtle Labs

Gallery wiring in progress

No learner projects are automatically public. Published entries will appear here only after an explicit publication step.

What a project card can hold

WorldSpec revision, Minecraft output, image or video, learner reflection, selected Turtle exchange, build history, and links to remixes or descendants.

Why this matters

The public artifact is evidence of thinking and making, not merely a polished final product. Revision histories can show how an idea changed, where Turtle misunderstood something, what the learner rejected, and what emerged only after construction or inhabitation.

Discord Turtle Lab

The preferred field-test experience is for /turtle idea:... to start a persistent Turtle Lab session and, next, a dedicated Discord thread. The learner should then talk normally with Turtle while the same WorldSpec evolves underneath the conversation.

Persistent WorldSpecs

Each session receives a session ID and WorldSpec ID. Turns and WorldSpec revisions are stored separately so the learner's original language, Turtle's interpretations, and subsequent revisions remain distinguishable. Portable WorldSpecs remain exportable as YAML/JSON artifacts.

LLM conversation + RAG + security

Turtle's conversational layer uses the Turtle Charter as trusted instruction while learner language, retrieved material, Discord history, Minecraft text, and prior model output remain untrusted project data. Retrieval will supply bounded context such as the current WorldSpec, learner definitions, unresolved concepts, active constraints, recent dialogue, relevant revisions, and intentionally attached project materials.

learner turn → retrieve bounded context → Turtle Charter → LLM dialogue → WorldSpec delta → deterministic validation → persist revision → reply

Build-in-public rule

Meaningful architecture, pedagogy, integration, research-data, and WorldSpec milestones should be reflected on the public TurtleBlock AI site as part of the same work cycle. Failures and reversals count as milestones too.
