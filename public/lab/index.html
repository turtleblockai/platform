Private conversation, public artifact

A Turtle conversation is private by default. Turtle Lab is not a raw Discord feed. A learner chooses what becomes public: a project title, a WorldSpec snapshot, selected build outputs, selected dialogue, and reflection.

private dialogue → persistent WorldSpec → learner chooses what to publish → curated Turtle Lab artifact

Research lineage in practice

Turtle Lab documents how ideas from Dr. Bryan P. Sanders' research program move into working infrastructure. The Dr. Bryan P. Sanders TurtleBlock AI research ontology begins with the 2019 dissertation's Dedoose document analysis of Dewey, Freire, and Papert. The original 17 codes, precept mappings, metrics, and source relationships remain a protected research-analysis layer; later Sanders-authored tools, publications, Turtle Charter mappings, and WorldSpec mappings are added as explicitly subsequent layers.

Dedoose source coding → authored CTC tools → later Sanders research → Turtle Charter + WorldSpec → operational Turtle

The latest D1 extension also represents Sanders' seven Critical Techno Constructivism tenets as an authored Tenet → Question → Action framework. That means the system can eventually retrieve a pedagogical move, not just a keyword.

Field-test sparks

Before public learner publishing is switched on, these are curated examples from Dr. Bryan P. Sanders' own Turtle field tests. They show the kinds of meaning Turtle needs to preserve rather than collapsing a learner's language into a few keywords.

Abandoned village / light of rebirth

“I want to make an abandoned village that has clear structures that are in disarray but were once nice, and then in the corner somewhere of the village a little shining light of hope of rebirth.”

The interesting problem is not merely “village.” Turtle needs to retain history, decay, spatial contrast, memory, hope, symbolism, and the relationship between ruin and renewal.

Glowing river / hamburger stand

“Let's make a river that has glowing deep depths and a fishing pier with a hamburger stand.”

A deliberately odd combination is useful: depth, light, water, commerce, fishing, humor, adjacency, atmosphere, and possible ecological consequences all coexist.

Process, not surveillance

The public artifact should show thinking and making without publishing the whole private conversation by default.

Discord Turtle Lab

The preferred experience is for /turtle idea:... to start a persistent Turtle Lab session and, next, a dedicated Discord thread. The learner should then talk normally with Turtle while the same WorldSpec evolves underneath the conversation.

Persistent WorldSpecs

Each session receives a session ID and WorldSpec ID. Turns and WorldSpec revisions are stored separately so the learner's original language, Turtle's interpretations, and subsequent revisions remain distinguishable.

LLM conversation + RAG + security

Turtle's conversational layer uses the Turtle Charter as trusted instruction while learner language, retrieved material, Discord history, Minecraft text, and prior model output remain untrusted project data.

learner turn → retrieve bounded context → Turtle Charter → LLM dialogue → WorldSpec delta → deterministic validation → persist revision → reply
